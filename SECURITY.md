# Security Policy

Security is important to Nexment.

If you discover a security vulnerability in the Nexment website or this repository, please report it privately rather than opening a public issue.

## Reporting a Vulnerability

Email:

**security@nexment.org**

Please include as much relevant information as possible, such as:

- A description of the vulnerability
- Steps to reproduce it
- The affected page, feature, or component
- Potential impact
- Screenshots, logs, or proof of concept where appropriate

Please do not publicly disclose the vulnerability until Nexment has had reasonable time to investigate and address it.

## Non-Security Issues

For bugs that do not involve security, please open a GitHub issue.

For general questions, contact:

**contact@nexment.org**
