# Contributing to Nexment

Thanks for your interest in Nexment.

This repository is primarily maintained by the Nexment team. We do not currently accept direct code contributions or pull requests.

However, bug reports and issues are welcome.

## Reporting a Bug

If you find something that is broken or behaving unexpectedly, please open an issue.

Please include:

- What happened
- What you expected to happen
- Steps to reproduce the issue
- Relevant browser or environment information
- Screenshots or logs when useful

Please search existing issues before opening a duplicate.

## Feature Ideas

Feature requests and product ideas should not be submitted as code contributions.

Send them to:

**hello@nexment.org**

## Security Issues

Please do not publicly disclose security vulnerabilities.

Report security issues privately to:

**security@nexment.org**

For more information, see `SECURITY.md`.

## Pull Requests

Pull requests are not currently part of the contribution workflow for this repository.

This may change in the future.
